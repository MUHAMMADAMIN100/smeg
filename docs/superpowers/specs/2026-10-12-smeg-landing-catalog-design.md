# SMEG Tajikistan — лендинг-каталог. Спецификация

Дата: 2026-10-12. Статус: утверждена заказчиком в чате («начинай»).

## 1. Цель

Витрина официального партнёра SMEG в Таджикистане (Instagram `smeg_tjk`, Истаравшан).
Сайт продаёт бренд и переводит посетителя в WhatsApp / Telegram / звонок с уже
выбранным товаром и цветом. Корзины и оплаты нет.

Успех: посетитель за 10 секунд понимает «это SMEG, итальянское ретро, официально,
в Таджикистане», находит нужную категорию, выбирает цвет и нажимает «Заказать».
Дизайн богатый, динамичный и не похожий на типовой ИИ-шаблон.

## 2. Стек

- Next.js 16 (App Router, Turbopack, `cacheComponents`), React 19, TypeScript.
- Tailwind CSS 4 (токены через `@theme`), Motion (`motion/react`) для анимаций.
- `next-themes` для переключателя светлой/тёмной темы, `lucide-react` для иконок.
- `next/font/google`: Prata (заголовки) + Onest (текст). Оба с кириллицей.
- Данные товаров — статические TypeScript-файлы, без БД и бэкенда.
- Тесты: Vitest для `lib/`, Playwright для e2e-прогона как пользователь.
- Деплой: Vercel (позже).

## 3. Страницы и маршруты

| Маршрут | Что показывает |
|---|---|
| `/` | Лендинг: все блоки из раздела 4 |
| `/catalog` | Каталог с фильтрами по категории и цвету (query-параметры `category`, `color`) |
| `/catalog/[slug]` | Страница товара: галерея по цветам, характеристики, цена, заказ, похожие товары |
| `not-found` | Фирменная 404 |

## 4. Блоки лендинга (сверху вниз)

1. **Шапка** — липкая, прозрачная поверх hero, при скролле кремовая с размытием. Лого «smeg tajikistan», меню (Каталог, Категории, Цвета, О бренде, Контакты), переключатель темы, кнопка «Заказать».
2. **Hero** — асимметричный: огромный заголовок Prata слева, вырезанный холодильник FAB28 на пастельном «пятне» справа, бегущая строка-лента «Made in Italy · с 1948 · официальный партнёр». Плавающие мини-карточки (чайник, тостер) с параллаксом. CTA «Смотреть каталог» и «Написать в WhatsApp».
3. **Категории** — 6 круглых пастельных плиток как highlights в Instagram: Холодильники, Плиты, Печи, Кофемашины, Тостеры, Чайники (+ Аэрогриль). Ведут в `/catalog?category=…`.
4. **Подбор по цвету** («Цветовая студия») — липкая секция: слева список цветов SMEG (пастельно-голубой, розовый, кремовый, мятный, красный, чёрный, белый), справа холодильник, который меняет фото и фон под выбранный цвет. Кнопка «Заказать в этом цвете».
5. **Бестселлеры** — горизонтальная «полка» с карточками товаров (скролл по горизонтали, перетаскивание), у карточки точки-цвета, цена, кнопка «Подробнее».
6. **Промо предзаказа** — аэрогриль Dual Flavour, крупное фото, бейдж «Доступен по предзаказу», выбор цвета (белый/чёрный/мятный/голубой), кнопка «Забронировать».
7. **О бренде** — редакционный блок: цифры (с 1948, Италия, Гвасталла), факты, цитата, фото lifestyle. Нумерация 01/02/03.
8. **Отзывы + Instagram** — карусель отзывов (примерные тексты), блок «9 000+ подписчиков» с кнопкой на профиль.
9. **Доставка, гарантия, рассрочка + FAQ** — три плитки (доставка по Таджикистану, официальная гарантия, рассрочка через «Алиф») и аккордеон вопросов.
10. **Контакты** — адрес, часы 09:00–21:00 ежедневно, телефон, WhatsApp, Telegram, Instagram, карта-заглушка (OSM iframe или стилизованный блок).
11. **Подвал** — огромная надпись SMEG, навигация, соцсети, «Официальный партнёр SMEG в Таджикистане».

## 5. Данные

`src/data/site.ts` — контакты (телефон, WhatsApp, Telegram, Instagram, адрес, часы). Заглушки, заказчик заменит.

`src/data/colors.ts` — палитра SMEG: id, название RU, HEX, подходящий фон-пятно.

`src/data/categories.ts` — id, slug, название RU, описание, цвет плитки, иконка.

`src/data/products.ts` — 25–35 товаров:
```ts
type Product = {
  slug: string; name: string; model: string; category: CategoryId;
  price: number;            // сомони, ориентировочно
  oldPrice?: number; badge?: 'new' | 'preorder' | 'hit';
  short: string; description: string;
  specs: { label: string; value: string }[];
  variants: { color: ColorId; image: string; sku: string }[];
  featured?: boolean;
}
```
Фото: официальные с smeg.com, скачаны в `public/products/<slug>/<color>.jpg|png`.

## 6. Заказ

`src/lib/order.ts` строит ссылки:
- WhatsApp: `https://wa.me/<phone>?text=<encoded>`
- Telegram: `https://t.me/<user>?text=<encoded>`
- Звонок: `tel:+992…`
Текст: «Здравствуйте! Хочу заказать {name} ({model}) в цвете {color}. Цена на сайте {price} TJS.»

## 7. Дизайн-система

Палитра из Instagram магазина (highlights + посты):
- Крем/фон `#F6F1E8`, карточка `#FFFDF9`, камень `#E9DFD1`, чернила `#15130F`.
- SMEG красный `#D7282F`.
- Пастель: голубой `#A8D3E6`, розовый `#F3C3CE`, кремовый `#F2E2B8`, мятный `#BFDCC9`, сливочный `#FFF4D6`.
- Тёмная тема: фон `#121110`, карточка `#1C1A17`, текст `#F3EEE6`; товары лежат на кремовых «подносах», чтобы белые фото выглядели как в студии.

Типографика: Prata для заголовков (display, обычное начертание, крупные кегли `clamp`), Onest 400/500/600 для текста и кнопок, мелкие подписи uppercase с трекингом.

Ощущение «не ИИ»: асимметрия, редакционная сетка, нумерация секций, тонкие линии вместо теней, лёгкое зерно поверх фона, бегущие строки, горизонтальные полки, крупная типографика, пастельные «пятна» под товарами, ни одного фиолетового градиента и стеклянных карточек.

Движение: появление по скроллу со стаггером (Motion), параллакс в hero, смена цвета в студии через `layout`/`AnimatePresence`, наклон карточки по курсору, `prefers-reduced-motion` отключает всё лишнее.

## 8. Тестирование

- Vitest: формат цены, построение ссылок заказа, целостность данных (уникальные slug, у каждого варианта есть файл фото, категории существуют).
- Playwright: главная, каталог с фильтрами, страница товара, переключение темы, кнопки заказа ведут на корректные ссылки, мобильная ширина 320/375/768/1440, консоль без ошибок, 404.
- `next build`, `eslint`, `tsc --noEmit` без ошибок.

## 9. Вне объёма

Корзина, оплата, админка, многоязычность, бэкенд, аналитика.
